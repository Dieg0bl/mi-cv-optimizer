# Repository Description for GitHub About Section

## Concise Description (for GitHub About section):
🚀 AI-powered CV/Resume optimizer that helps job seekers improve their resumes using Hugging Face Transformers. Upload a PDF, get AI-enhanced content with better structure and formatting. Built with React frontend and Python Flask backend.

## Detailed Description:
AI-powered web application that optimizes CVs/resumes using machine learning. Users upload PDF resumes, and the app uses Hugging Face's T5-base model to restructure and improve content while preserving the original language. Features React frontend with file upload, Flask API backend, PDF processing, and automated CV enhancement for better job application success.

## Technologies:
React • Python • Flask • Hugging Face Transformers • PyTorch • PDF Processing • AI/ML
